# Blinkit Landing Page Clone

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `assets/` — SVG illustrations used by the page
- `screenshots/desktop.png` — desktop layout preview
- `screenshots/mobile.png` — mobile layout preview

## Run locally
1. Extract the project folder.
2. Open the folder in VS Code.
3. Run `index.html` with the Live Server extension, or open it directly in a browser.

The page is a static HTML/CSS assignment clone. Search, login, cart and order buttons are visual only.
